Cairn

Support

Cairn is in public TestFlight beta. Feedback is welcome.

Get help

For setup, troubleshooting, or feature questions, open a GitHub issue. Include your Cairn version, device and OS version, and the steps that led to the problem.

Never include a SimpleFIN setup token, Access URL, account number, transaction export, or other financial information in a public issue.

Security issues

Do not open a public issue for a security problem. Use GitHub private vulnerability reporting or follow the contact details in the security policy.

Before contacting support

  • For bank connections, confirm your SimpleFIN Bridge account is active and the institution is available there.
  • For cross-device sync, confirm each device uses the same Apple Account and has iCloud Drive and iCloud Keychain enabled.
  • For Wallet data, use an iPhone or iPad; a Mac shows synced Wallet data but cannot independently read FinanceKit.
